# Tabyl

Tabyl — веб-приложение для поиска потерянных и найденных вещей. В MVP участники смогут размещать объявления с фото, искать их по категории, связываться с авторами и отмечать возврат предмета.

Проект на этапе настройки. Нурбол передаёт команде план разработки и задачи отдельно.

## Как начать работу

1. После получения приглашения примите его и откройте [репозиторий Tabyl](https://github.com/nurbo1-create/tabyl).
2. Клонируйте репозиторий и откройте его папку в Codex или Claude Code.
3. Получите Master Guide у Нурбола и прочитайте раздел 0 и свою секцию из раздела 8. Начните с небольшой задачи в отдельной ветке и откройте Pull Request для ревью.

Точки входа для агентов — [AGENTS.md](AGENTS.md) для Codex и [CLAUDE.md](CLAUDE.md) для Claude Code.
