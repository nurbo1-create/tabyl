# Tabyl — инструкции для Codex

Актуальное состояние проверяй по [nurbo1-create/tabyl](https://github.com/nurbo1-create/tabyl).

1. Если участник ещё не назвал себя, спроси, кто он из команды — Нурбол, Абыл, Нурбек или Амир.
2. Проверь, что рабочая копия относится к `nurbo1-create/tabyl` и что у участника есть доступ, необходимый для его задачи. Если рабочая копия уже есть, используй её.
3. Прочитай Master Guide, который Нурбол передаёт команде отдельно. Если файл ещё не приложен, попроси участника прислать его. Затем прочитай раздел 0 и секцию участника в разделе 8, сверь задачи с текущим состоянием репозитория и предложи первый небольшой Pull Request.

Работай в пределах согласованной задачи и роли. Используй отдельную ветку и отправляй изменения на ревью через Pull Request в `main`. Указывай только фактически выполненные проверки.
